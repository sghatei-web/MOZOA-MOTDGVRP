# Christofides Set E benchmark files

The original `.vrp` instance files are not redistributed in this repository.
Download the Christofides Set E instances from the public CVRPLIB/NEO
benchmark collection and place them in this directory before running the Set E
experiments.

Required filenames:

- E-n13-k4.vrp
- E-n22-k4.vrp
- E-n23-k3.vrp
- E-n30-k3.vrp
- E-n31-k7.vrp
- E-n33-k4.vrp
- E-n51-k5.vrp
- E-n76-k7.vrp
- E-n76-k8.vrp
- E-n76-k10.vrp
- E-n76-k14.vrp
- E-n101-k8.vrp
- E-n101-k14.vrp
